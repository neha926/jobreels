# KaamReels | 100% Free Job & Skill Reels Platform
> Built according to the Free Job + Reels Platform App Development Guidelines & PRD.

## Quick Start Instructions

To run the interactive mobile-first application in your browser:

```powershell
# 1. Open Terminal and enter the project folder
cd C:\Users\NEHA\Downloads\TaskB\freejob-reels-platform

# 2. Start the development server
npm run dev
```

Then open `http://localhost:5174` in your browser.

## Key Features Implemented:
1. **Vertical 9:16 Reels Feed:** Autoplay video simulation, like counter, comments drawer, WhatsApp sharing, save reel, mute/unmute, and in-feed sponsored job card with **APPLY NOW**.
2. **Search Jobs:** Filters for Welder, CNC, Driver, Electrician, Office, Location (Chakan, Pune, Mumbai), Salary, and Experience.
3. **Automatic Digital Resume:** Professional resume generator with PDF print/download and WhatsApp share.
4. **One-Tap Apply:** Candidate applies with 1 tap, sends digital resume to HR, and tracks status in real-time.
5. **In-App Chat & Interview:** Pre-built quick reply templates, interview date/time invite, and **"Open in Google Maps"** navigation button.
6. **Multi-Language Support:** Instant switching between English, Hindi (हिन्दी), and Marathi (मराठी).
7. **Employer / HR Panel:** Post a free job in 2 minutes, candidate applicant pipeline (Shortlist, Schedule Interview, Select, Reject).
8. **Admin Anti-Fraud Console:** Review reported jobs (Money asking scam, fake company, wrong salary), with 1-click ban and company verification.
9. **Full PRD Approval Package:** Complete architecture, schema, timeline, and cost breakdown in `DELIVERABLES_FOR_APPROVAL.md`.
